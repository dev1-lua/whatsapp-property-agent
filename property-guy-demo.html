How to demo

  1. Click Seed demo data to load 3 properties, 4 tenants, 4 vendors.
  2. Add yourself as a tenant in the Tenants tab so the agent recognizes you.
  3. Run npx lua chat -e production in your terminal — the agent will identify you and walk through a maintenance request.
  4. Watch new tickets appear in the Open Tickets tab.

Chat with the agent

The agent has two modes:
 • Tenant mode — identify yourself with name + phone (must match a seeded tenant) and file/check maintenance tickets, e.g. "Hi I'm Laura Murphy at +353861234567, my kitchen sink is leaking".
 • Admin mode — portfolio-wide read-only Q&A, e.g. "Show me open tickets in Dublin" or "Which vendors handle plumbing?".
Edited data via the admin UI? Click New thread to start a fresh chat — the agent re-reads live data on every tool call, but a new thread guarantees no stale conversational context.
